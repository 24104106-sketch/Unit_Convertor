# Smart Unit Converter

A simple and responsive web application that converts values between different measurement units. The project is developed using HTML, CSS, and JavaScript with an easy-to-use interface for quick and accurate unit conversions.

## Features

- Length Conversion
- Weight Conversion
- Temperature Conversion
- Time Conversion
- Responsive User Interface
- Instant Conversion Results
- User-Friendly Design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
Smart-Unit-Converter/
│── index.html
│── style.css
│── script.js
│── README.md
```

## How to Run

1. Clone the repository

```bash
git clone https://github.com/24104106-sketch/Unit_Convertor.git
```

2. Open the project folder.

3. Open `index.html` in any web browser.
